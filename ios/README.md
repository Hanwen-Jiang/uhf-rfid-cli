# iOS —— 为什么不能直接插线，以及怎么做

## 结论先说

**iOS 上做不到「插 USB 线直接发串口指令」**，这是系统限制，不是没写代码：

- iOS 不给普通 App 开放 USB 串口。要接 USB 设备只有两条路：
  - **MFi 认证**：跟苹果申请、硬件里加认证芯片、走 `ExternalAccessory` 框架。
    周期长、要花钱，而且读写器不是我们造的，改不了它的硬件。
  - **USB-C 上的 CDC 设备**：iOS 17 起 iPad/Mac 对部分 CDC-ACM 设备有支持，
    但 iPhone 上依然不可用，且没有任何公开稳定的串口 API。
- 所以 iOS 现实的选择只有两个：**BLE 蓝牙** 或 **网络（TCP）**。

## 方案 A：BLE 串口模块（推荐，不依赖读写器型号）

买一个 BLE 转串口模块（HC-08、JDY-08、AT-09 这类，几十块钱），接到读写器的
RS232/TTL 串口上，手机用 CoreBluetooth 连它，App 往特征值里写帧、从通知里读应答。

```
[读写器 RS232] <--> [BLE 串口模块] <--BLE--> [iPhone App]
```

要做的：

1. 模块配成透传模式，波特率设 **115200 8N1**（和原厂 GUI 一致）。
2. App 用 `CoreBluetooth`：
   - 扫描：找名字像 `HC-08` / `JDY` / `AT-09` 的设备，或按 Service UUID 过滤
     （透传模块一般用 `0000FFE0-0000-1000-8000-00805F9B34FB`，
     特征 `0000FFE1-…`，写+通知）。
   - 连上后订阅通知特征，把校验通过的帧累积起来解析。
3. **协议层一行都不用改**：帧格式、校验、`0x8A`→`0x53` 那套逻辑和
   `re/rfidframe.py` 完全一样，直接照抄成 Swift 就行。

要注意的两点：

- **BLE 的 MTU 小**（默认 20 字节，协商后一般 185~512）。写标签的 `0x82` 帧
  有 29 字节，超过默认 MTU 就要分片写，或者用「写长包」(Write Long)。
  建议连接后先协商 MTU。读 EPC/TID 的 `0x8A` 帧只有 9 字节，不受影响。
- **吞吐比有线低**，写整块 EPC/TID 会慢一点，读 EPC/TID 完全够用。

## 方案 B：网络（如果读写器带网口/WiFi 模块）

原程序本来就支持 TCP：默认 `<读写器>:8080`（见 `re/PROTOCOL.md` 的传输一节）。
如果你的读写器有网口或 WiFi 模块，iOS 直接用 `Network.framework` 开个 TCP 连接，
把同样的帧写进去就行 —— 这是最省事的路，**不用买任何硬件**。

```swift
let conn = NWConnection(host: "192.168.0.178", port: 8080, using: .tcp)
// 然后把 RfidFrame.build(...) 出来的字节 send 出去，收到的字节累积后解析
```

前提是读写器本身有网络能力。你手上这台目前是 USB 接电脑的，
**先确认一下读写器有没有网口 / 能不能插 WiFi 模块**——有的话 iOS 端就很简单了。

## 方案 C：电脑/树莓派当桥（不用改硬件，两端都能用）

读写器还是 USB 接在一台常开的电脑或树莓派上，那台机器跑一个小服务把串口转成
TCP/WebSocket，手机 App 连它。iOS 和 Android 都能用，一行驱动都不用装。

这个方案的代码可以用现成的 `rfidctl.py --tcp` 起，或者写一个几十行的桥接脚本。

```
[读写器 USB] <--> [电脑/树莓派: 串口<->TCP 桥] <--WiFi--> [手机 App]
```

---

## 想做哪个？

按省事程度排：

1. **读写器有网口** → 方案 B，iOS 直接连，最省事。
2. **读写器只有 USB，但有台常开的机器** → 方案 C。
3. **都不满足** → 方案 A，买个 BLE 模块接上。

三个方案的**协议层是同一份代码**，先在 Android 上验证过的那套
（`android/app/src/main/java/com/hanwenjiang/uhfrfid/RfidFrame.java`）
直接翻成 Swift 即可，自测用例也能照搬（对着 `re/capture53.hex` 解出
EPC=`E28069150000402008B83072` / TID=`E28069152000402008B83072`）。

> 注意：Apple 开发者账号要有（免费账号也能装到自己的手机上，7 天有效期；
> 付费账号 $99/年才是长期）。CoreBluetooth 不需要 MFi，方案 A 能用免费账号跑。
